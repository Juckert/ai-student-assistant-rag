# ИИ-ассистент студента

Прототип системы вопросов и ответов для студентов программ по искусственному интеллекту.

Проект построен на связке `RAG + LLM`:
- база знаний собирается из файлов `PDF`, `TXT` и `CSV`;
- поиск идёт по эмбеддингам с дополнительной лексической фильтрацией;
- итоговый ответ формируется локальной моделью через `Ollama`;
- интерфейс реализован на `Streamlit`.

## Возможности

- вход в систему по ролям `admin` и `student`;
- саморегистрация студентов;
- история диалогов для каждого студента;
- отдельные уведомления о новых ответах администратора;
- ответы только на основе найденного контекста;
- показ источников для найденных ответов;
- скрытие источников, если точного ответа в базе нет;
- автоматическая передача вопросов без ответа администратору;
- ручное пополнение базы знаний ответами администратора;
- отклонение вопросов, не относящихся к теме системы;
- загрузка файлов и переиндексация базы знаний через интерфейс администратора.

## Как работает система

1. Студент задаёт вопрос в свободной форме.
2. `RAG` ищет подходящие фрагменты в базе знаний.
3. Агент передаёт найденный контекст в `Ollama`.
4. Модель формирует ответ только по найденным данным.
5. Если точной информации нет, студент получает честный ответ, а вопрос попадает в очередь для администратора.

## Роли в системе

### Студент

- задаёт вопросы;
- видит только свою историю диалогов;
- может зарегистрировать новый аккаунт;
- получает сообщение, если вопрос передан администратору на актуализацию;
- видит отдельное уведомление, когда по его вопросу появляется новый ответ.

### Администратор

- загружает новые файлы в `data`;
- пересобирает индекс по одному файлу или по всей папке `data`;
- видит список пользователей;
- видит очередь вопросов без ответа;
- может ответить на вопрос, сразу добавить его в `data` и обновить индекс;
- может отклонить вопрос, если он не относится к теме системы.

## Обновление базы знаний

Если появилась новая информация, есть два сценария:

- если новый файл полностью заменяет старый, лучше заменить старый файл и затем пересобрать индекс по всей папке `data`;
- если новый файл содержит только новые данные и не дублирует старые, можно добавить его в `data` и тоже пересобрать индекс по всей папке `data`.

Практически это выглядит так:

1. Добавить или заменить файл в `data`.
2. Зайти под администратором.
3. Нажать построение индекса по всей папке `data`.

Если вопрос пришёл через очередь без ответа, администратор может ответить на него прямо в интерфейсе. В этом случае система:
- добавит новую пару вопрос-ответ в `data/admin_added_qa.csv`;
- пересоберёт индекс;
- уберёт вопрос из очереди;
- покажет студенту отдельное уведомление о новом ответе.

## Хранение данных

- база знаний хранится в `db/`;
- пользователи, история диалогов и очередь вопросов без ответа хранятся в `storage/assistant_state.json`.
